# SDL Graphics Library
Uses SDL2 to create a basic graphics library. The goal is to provide support for the creation of basic plots and also provide graphical support for 2D animations (specifically for things like Conway's Game of Life and other Cell automata).

## Roadmap
- [ ] Implement basic window creation and pixel/rectangle drawing
- [ ] Implement basic plotting functions
    - [ ] Curve drawing with splines
- [ ] Implement animation creation for things like Conway's Game of Life
    - [ ] Allow for exporting of frames to allow for video creation with ffmpeg
